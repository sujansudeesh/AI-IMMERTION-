# Redacted evidence records

No participant interviews, original AI exports, usability results or demo recordings are included here yet. The current assistant-authored [revision summary](ai-revision-2026-10-06.md) is included and is not an original exported transcript or participant record. This folder's README is guidance, not a research record.

## Suggested files

Use meaningful names such as `interview-P01-YYYY-MM-DD.md`, `observation-O01-YYYY-MM-DD.md`, `test-T01-YYYY-MM-DD.md`, `ai-session-AI01-YYYY-MM-DD.md` and `demo-D01-YYYY-MM-DD.md`. Use actual dates only. Replace format tokens when an activity occurs; do not create apparently completed empty records.

Each record should state its ID, activity date, responsible researcher, participant code/role where relevant, consent scope, task/context, observations or original excerpt, limitations and private-original reference. A transcript is not the same as a paraphrase. Label translations and retrospective reconstructions.

Store recordings, full names, phone numbers, signed consent and private store data outside the public repository. Only add anonymized or consented redacted excerpts suitable for publication. A private reference should identify how the team can locate an original without publishing the private contents or a public-access link.

Add the relative file path to the correct array in `data/project-review.json`. Markdown notes do not update the website automatically. Check both the record and summary before committing. A file's existence and a consent checkbox do not establish authenticity; a human must verify them.
