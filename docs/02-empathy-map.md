## How to complete a map

Use SAYS for genuine recorded speech and DOES for observed actions. Use THINKS and FEELS for a participant's own report or explicitly mark them as researcher interpretations. Record the participant code, actual date, interview/observation ID and exact source location supporting each entry. Include contradictory findings rather than keeping only evidence that favours the app.

Connect completed maps to the [research records](01-empathy-research.md), [journey map](12-user-journey-map.md) and [problem definition](03-design-thinking-problem-statement.md). Publish only consented, redacted records; keep contact details and private originals out of the repository.
